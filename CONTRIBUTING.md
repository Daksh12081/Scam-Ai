# Contributing

## Branches

- main (protected)
- develop
- feature/<feature-name>

## Workflow

1. Create a feature branch.
2. Commit changes.
3. Open a Pull Request into develop.
4. Merge into main only when the build is demo-ready.

## Coding Standards

- Follow CONTRACT.md.
- Never commit secrets.
- Update both backend models and frontend types if contracts change.
