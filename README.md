# Sentinel

AI-Orchestrated Fraud Defense Platform built for the MENA Ignite Hackathon.

## Tech Stack

### Frontend
- React
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- PostgreSQL
- WebSockets
- Pydantic

### AI
- Groq Llama 3.3
- Groq Whisper
- Pydantic AI

### Telecom
- Nokia Network-as-Code
- CAMARA APIs

main      -> Stable / Demo Ready

feature/* -> Feature Development
